# My Weather Pal

Create a new project from the GitHub repo https://github.com/rod1974b-lgtm/zip2weather-pal. It is the "My Weather Pal" app: a simple weather app using Open-Meteo that shows current temperature, hourly forecast for today, a 7-day forecast, city search, and a use-my-location option with a pre-dialog explaining why. It should have no Supabase and no trackers, include a /privacy page, and work offline with cached last weather.
